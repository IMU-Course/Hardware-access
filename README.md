# Hardware-access
Contains programs exercising the peripherals on the WeMos esp32-s3 mini pro board.
The esp32-s3 mini pro board has the following peripherals installed on its CPU board:
* a ws2812 type rgb LED
* a IR LED
* 3 switches
* a 128x128 pixel screen controlled by a st7789 display controller
* a qmi8658 6 DoF IMU  
This repository contains programs demonstrating the used of these devices with the help of simple MicroPython programs
